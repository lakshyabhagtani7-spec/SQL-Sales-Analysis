# Restaurant Sales & Customer Analysis Using SQL

## Project Overview
This project focuses on analyzing restaurant sales and customer behaviour using SQL. It involves solving business-oriented problems using a restaurant database consisting of four tables: Customers, Restaurants, Menu, and Orders.

The objective is to extract meaningful insights related to sales performance, customer purchasing patterns, restaurant revenue, menu pricing, and order delivery.

## Database Schema

The project uses the following four tables:

- **Customers:** Customer ID, Name, Age, Gender
- **Restaurants:** Restaurant ID, Restaurant Name, City, Location
- **Menu:** Menu ID, Restaurant ID, Item Name, Category, Restaurant Price, App Price
- **Orders:** Order ID, Menu ID, Customer ID, Quantity, Order Date, Order Time, ETA, Delivery Time

## Key SQL Concepts & Techniques

- Data Filtering and Sorting
- Aggregate Functions
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Subqueries and Correlated Subqueries
- Common Table Expressions (CTEs)
- Window Functions
- ROW_NUMBER(), RANK(), DENSE_RANK()
- LAG() and Running Totals
- Self Joins
- CASE Statements
- Date and Time Functions

## Business Problems & Analysis

The project covers multiple business scenarios, including:

- Identifying restaurants based on total order volume.
- Analyzing top customers based on purchase quantity and spending.
- Calculating monthly revenue and restaurant-wise revenue.
- Evaluating customer ordering behaviour and preferences.
- Identifying the most expensive and frequently ordered menu items.
- Comparing restaurant prices with application prices.
- Analyzing delivery delays and order performance.
- Calculating restaurant commissions and markup percentages.
- Ranking restaurants and menu items based on business performance.
